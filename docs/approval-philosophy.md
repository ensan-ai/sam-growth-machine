# Human Approval Philosophy

Sam remains the ultimate human authority and final approval layer.

The future system must support four human decisions:

- APPROVE
- REQUEST CHANGES
- REJECT
- PAUSE

The current high-level growth loop places a Sam approval gate after the Brain and Jax stage and before Maro. Maro's Phase 2F contract defines the minimum explicit, version-bound approval reference required before publication. The system still does not define approval production, validation infrastructure, response times, delegation, or complete rework routing.

The system may become more autonomous over time, but autonomy must be earned through approved policies and evidence. Autonomy is not inferred from successful execution and must never remove Sam's ultimate authority.

Phase 1 does not implement queues, approval logic, notifications, or user interfaces.
