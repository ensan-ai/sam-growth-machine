# Schemas

This directory holds repository-level specification schemas.

- ai-employee-manifest.schema.json validates the common static employee manifest shape.
- workflow-spec.schema.json validates the non-executable high-level workflow specification.

Employee-specific input and output schemas live inside each employee package. Travis, Saly, Adam, Brain, Jax, Maro, and Lara have strict reviewable interfaces from their authorized Phase 2A–2G definition work. These contracts specify artifacts; they do not implement execution.
